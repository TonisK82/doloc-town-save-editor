# v0.1.1 正式发布 / Stable release

- 道具列表新增垂直滚动条 / Vertical scrollbar for the item catalog.
- 中英文界面切换和道具搜索 / Chinese-English interface and item search.
- 修改玩家金钱（0–999,999,999），同步存档概览 / Edit player money and save overview.
- 语言切换保留未保存修改 / Preserve pending edits when switching languages.

下载 ZIP 后解压，运行 DolocTownSaveEditor-v0.1.1.exe，无需安装 Python。完全退出游戏，建议先备份 `doloc-save-0.data`。修改后点击“另存为”，选择原存档目录中的 `doloc-save-0.data` 并确认覆盖。

Extract the ZIP and run DolocTownSaveEditor-v0.1.1.exe. No Python needed. Quit the game completely; backing up `doloc-save-0.data` first is recommended. After editing, click “Save as” and overwrite `doloc-save-0.data` in the original save folder.

已验证滚动、中英文切换与编辑保留、金钱边界和加密回读、备份及独立程序启动。仓库作者已完成游戏内实测，确认修改器可用，现转为正式发布。

Verified scrolling, language switching, pending edits, money bounds, encrypted round-trip, backups and packaged startup. The repository owner has tested the editor in-game and confirmed that it works. This version is now a stable release.
